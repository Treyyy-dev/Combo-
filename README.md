# Combo

A 2.5D anime fighting game that runs in the browser. Everything is in one file, `index.html`, with no build step.

## Play

Open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings → Pages → deploy from the `main` branch) and visit the page it gives you.

## What's in it

- 30 fighters, each with two skills and a cinematic ultimate
- Story (8 chapters), Versus, Team Battle, Survival and Training
- Gacha with 8 banners, paid for with gems earned by playing
- Intro and ending cutscenes with matchup dialogue
- 5 stages

## Controls

| | Keyboard / mouse | Controller | Touch |
|---|---|---|---|
| Move | A / D | Stick or D-pad | Drag left side |
| Jump | W / Space | A | Flick up or JUMP |
| Light attack | Left click / J | X | ATK |
| Heavy attack | Right click / K | Y | HVY |
| Dash | Shift | B | DASH |
| Skills | Q / E | LB / RB | S1 / S2 |
| Ultimate | R | RT | ULT |
| Guard | F / S | LT | GRD |

Progress is saved in the browser's local storage.
